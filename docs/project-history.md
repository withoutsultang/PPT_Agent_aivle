## 실행 기록

확인한 팀 산출물 `Step2_조별과제_AI_강사_Agent_v2_0.ipynb`의 저장 출력 기준입니다. 아래 cN은 JSON `cells[N]`이며 0부터 셉니다. 원본 교육 자료와 키 출력이 포함될 수 있는 노트북 전체는 저장소에 재배포하지 않습니다.

| 위치 | 입력 / 기록된 결과 |
|---|---|
| c94/c95 | 3장 처리, 대본 3개, 최종 영상 4분 5초·6.13MB, 퀴즈 6개 |
| c99 | 7장 처리, 최종 영상 9분 2초·12.69MB |
| c102 | Gradio 3장 처리, 최종 영상 4분 43초·7.17MB, 퀴즈 6개 |

재생 시간은 제작 소요시간이나 개선율이 아닙니다. 이 결과는 팀 통합 실행이며 특정 개인의 실행·평가 행위와는 구분합니다. 원본 파일 식별값(SHA-256): `b3864e302547d60e273d57f1641a690f3145fc49fb18d0a8b324365b749b5c1a`.

## 2026년 포트폴리오 정비

2026-10-29의 정비는 당시 팀 개발 이후의 유지보수입니다. 다음 내용을 현재 코드에 반영했습니다.

- 대본 프롬프트와 그래프 실행을 분리해 핵심 생성 로직을 읽고 검증하기 쉽게 정리
- 한 장·중간 장·마지막 장의 프롬프트 조건과 문맥 전달 검증
- 검색 출처 중복 제거, 도형 텍스트와 전체 슬라이드 이미지 전달
- 슬라이드 ID 기준 영상 순서 검증과 실행별 폴더 분리
- 퀴즈 JSON 계약 검증·재요청·생성 영상 보존
- 설치·환경 설정·로컬 실행 안내와 GitHub Actions 회귀 테스트 추가

현재 회귀 테스트는 모의 API 응답을 사용한 실제 LangGraph 실행과 FFmpeg 미디어 처리로 구성합니다. 유료 LLM/TTS 호출의 결과를 새로 측정한 것으로 소개하지 않습니다. 현재 변경을 2025년 당시 수행한 개인 경험으로 소급하지 않습니다.
