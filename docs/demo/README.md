# 슬라이드 전환 시연

[공개용 3장 PPT](health-check.pptx)는 헬스 체크 실패 원인, 인증 규칙 수정, 수정 결과 확인 순으로 구성했습니다.

2장 첫 문장을 비교하면 직전 설명을 이어받는 방식이 드러납니다. 아래 문장은 전환 설계를 설명하기 위해 직접 작성한 예시입니다.

| 입력 조건 | 2장 대본 예시 |
|---|---|
| 현재 슬라이드만 제공 | 점검 경로와 인증 규칙을 분리하는 방법을 살펴보겠습니다. 점검 전용 경로는 인증 없이 접근하도록 설정합니다. |
| 전체 목차와 직전 대본을 함께 제공 | 앞에서 본 401 응답은 점검 요청에도 로그인 규칙이 적용됐기 때문입니다. 그래서 점검 전용 경로만 인증 없이 열어줍니다. 이제 점검은 통과하고 업무 API는 여전히 보호되는지 확인해 보겠습니다. |

[프롬프트 구현](../../prompts.py)은 중간 장에 직전 대본의 끝부분과 다음 장 제목을 전달합니다. 첫 장은 도입, 마지막 장은 요약과 마무리를 맡습니다.

[실행 안내](../../README.md)에 따라 앱을 시작하고 예제 PPT를 올립니다. 생성 후 영상에서 세 장이 순서대로 재생되고 음성이 나오는지 확인합니다. 이어서 퀴즈가 여섯 문항이고 정답이 각 문항의 보기와 일치하는지 확인합니다.
